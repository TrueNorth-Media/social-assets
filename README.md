# TrueNorth social assets

Finished graphics, videos and PDF carousels for TrueNorth Consultants' social media posts.
This repository only holds approved, publish-ready files so Buffer can pick them up by public link.

## Layout

One folder per platform, then one folder per date (YYYY-MM-DD):

- `instagram/` Reels and carousel slides
- `tiktok/` videos and photo-mode slides
- `youtube/` Shorts
- `linkedin/` PDF document carousels and images
- `threads/` images and videos
- `x/` images
- `pinterest/` 2:3 pins
- `shared/` logos and reusable brand pieces

Example: `linkedin/2026-12-01/pay-per-booking.pdf`

## Rules

- Only owner-approved, finished files go here.
- Nothing private: no drafts, research, customer data, passwords or keys.
